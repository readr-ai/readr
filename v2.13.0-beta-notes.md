# v2.13.0 — beta release collateral (not committed)

## TestFlight "What to Test" (paste into App Store Connect)

Reading, but you can ask the book questions.

New in this build:
- Fixed: adding or testing a second AI provider key no longer breaks
  Ask/Article generation for your working provider. If you ever saw
  "provider rejected your API key" while your key was fine, this was it.
- Books now open in Single page layout by default — swipe to turn pages
  like a real book. Prefer continuous scrolling? It's one tap away in
  the Aa menu.

Things worth poking at:
- Connect an OpenAI or Anthropic API key in Settings → AI Providers,
  select a passage, and try "Ask" — answers should stream with sources.
- Turn highlights into an article: highlight a few passages → long-press
  the book cover → Create Article.
- Import your own EPUBs and PDFs; check the table of contents,
  footnotes, and images render correctly.

## Product Hunt launch-day summary of what shipped since v2.12.0

- #44 (major): saving any provider API key stole the "active" slot
  before validation and never gave it back on rejection — silently
  breaking Ask + Article Studio until relaunch. Fixed with a guarded
  activation policy (+10 regression tests).
- #42: EPUBs default to Single page (book-like) layout on first run.

## Remaining manual step after the upload lands

The TestFlight workflow uploads the build; distributing to the public
external group (which triggers Apple's Beta App Review) is done in App
Store Connect: TestFlight → the external group behind
https://testflight.apple.com/join/U5dBEsSG → add build 2.13.0 → it
auto-submits for beta review. Paste the What-to-Test text above when
prompted.
